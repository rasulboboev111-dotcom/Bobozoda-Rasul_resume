# Резюме | Бобозода Расул

Современное адаптивное веб-резюме на чистом HTML5 и CSS3 без JavaScript.

## Ссылка на резюме онлайн:
👉 [https://rasulboboev111-dotcom.github.io/Bobozoda-Rasul_resume/](https://rasulboboev111-dotcom.github.io/Bobozoda-Rasul_resume/)

## Особенности проекта:
- 100% чистый CSS без JavaScript для адаптивности и мобильного меню (через CSS Checkbox Hack)
- Семантическая вёрстка HTML5
- Иконочная библиотека Font Awesome 6
- Строгий современный дизайн без градиентов
- Полная адаптивность для мобильных телефонов, планшетов и ПК
